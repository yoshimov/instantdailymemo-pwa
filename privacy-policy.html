プライバシーポリシー

最終更新日: 2026年6月13日

Instant Daily Memo は、起動後すぐに今日の日記を書ける PWA です。本ポリシーは、本アプリにおける情報の取り扱いを説明します。

取得・保存する情報

本アプリは、次の情報を利用者のブラウザ内に保存します。

  • 利用者が入力した日記本文
  • 日記の保存日、更新日時
  • Google Calendar API 接続に必要な設定値
  • Google 接続状態を復元するためのフラグ

これらの情報は、IndexedDB または localStorage に保存されます。本アプリ独自のサーバーへ送信されることはありません。

Google Calendar API の利用

利用者が Google 接続を行った場合、本アプリは Google Calendar API を利用し、選択されたカレンダー内の今日の `memo` 予定を読み書きします。

  • 今日の `memo` 予定を検索します。
  • 既存の `memo` 予定がある場合、その説明欄を日記本文として読み込みます。
  • 保存時に `memo` 予定の説明欄を更新します。
  • 今日の `memo` 予定がない場合、新規の終日予定を作成します。

Google の access token はブラウザのメモリ上で扱い、永続保存しません。Google 接続の復元に必要なフラグのみ localStorage に保存します。

音声入力

音声入力はブラウザが提供する Web Speech API を利用します。音声認識の処理方法は、利用者のブラウザや OS、提供元の仕様に従います。

第三者提供

本アプリは、利用者が Google 接続を行った場合を除き、日記本文を第三者へ送信しません。Google Calendar API の利用時は、利用者の操作に基づき Google Calendar へ日記本文を送信します。

Cookie・解析ツール

本アプリは独自の Cookie やアクセス解析ツールを使用しません。ただし、Google 認証画面や Google Calendar API の利用時には、Google のサービスが Cookie 等を利用する場合があります。

データの削除

ブラウザに保存された日記データは、ブラウザのサイトデータ削除機能から削除できます。Google Calendar に保存された `memo` 予定は、Google Calendar 上で削除できます。

変更

本ポリシーは、必要に応じて変更されることがあります。重要な変更がある場合は、本ページ上で告知します。
